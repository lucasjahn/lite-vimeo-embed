# Lite Vimeo Embed - Project Overview

## Purpose
A lightweight, high-performance Vimeo embed custom element that renders approximately 224X faster than standard iframe embeds. Provides a better user experience by loading a static thumbnail first, then dynamically loading the Vimeo iframe only when the user clicks to play.

## Key Features
- Custom web component (`<lite-vimeo>`)
- Progressive enhancement support
- Significant performance improvements over standard embeds
- Uses Vimeo API directly
- Background image thumbnails with click-to-play functionality
